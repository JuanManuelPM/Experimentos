# Demo Engine V6 · Window Lab V3

Fast human-review showcase for Demo Engine V6.

## UX changes

- Six short animation chapters instead of one long demo.
- `RUN ALL` auto-advances through them.
- `NEXT ANIMATION` immediately stops the current chapter and starts the next.
- Scene rail can jump directly to any chapter.
- While a chapter is running, the engine owns the viewport and blocks accidental human scrolling/touch scrolling/scroll keys.
- The physical cursor is hidden only inside the stage during autoplay.
- Authority returns to FREE after the chapter/run.
- Text narration is faster.
- Game-like text voice is quieter and plays only on a fraction of characters.

## Chapters

1. Click + fast typing
2. Local scroll + page scroll
3. Common controls
4. Drag + resize
5. Annotation-only laser
6. Adaptive focus/zoom
