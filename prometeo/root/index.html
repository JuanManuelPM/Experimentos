CALIBRAR / REVISIÓN HUMANA

Diez observaciones. Una mejora del método.

Elegí una tanda, anotá qué no te gustó y adjuntá tus capturas. El registro se prepara para corregir las raíces en la próxima versión, no para parchear las obras.

Privacidad: las observaciones y capturas quedan en este navegador; no se envían a GitHub ni a servidores. Exportá el ZIP para conservarlas o compartirlas en el chat. No incluyas información sensible en capturas públicas.
