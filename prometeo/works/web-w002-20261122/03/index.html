02 / Sobre la práctica

Una forma
de mirar.

Iria Sola es una artista ficticia creada para este ensayo digital. Su práctica imaginaria trabaja con superficies erosionadas, pliegues de papel y estratos de luz. El archivo no representa exposiciones, propietarios ni materiales físicos existentes: reúne ocho composiciones digitales originales concebidas para una experiencia editorial de observación cercana.

PROCEDENCIA Y DERECHOS
Obras creadas para ARCHIVO ABIERTO mediante código generativo vectorial original, sin fotografías, marcas ni reproducciones artísticas de terceros. La técnica y las medidas son digitales. El código del visor está separado para su reutilización. Las referencias de diseño investigadas se acreditan en la documentación del proyecto.
