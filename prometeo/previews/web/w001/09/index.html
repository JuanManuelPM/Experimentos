03 / Antes de empezar

BUENAS
PREGUNTAS.

Esta escuela es un concepto de demostración. Los cursos, duraciones y contenidos son inventados para mostrar cómo podría funcionar un sitio de formación.

¿Necesito experiencia previa?

Los trayectos ficticios están pensados como introducción. No se exige experiencia previa para explorar sus contenidos.

¿Los talleres son presenciales?

La modalidad de enseñanza todavía no está definida porque MANO no es una institución real. No hay sedes ni horarios disponibles.

¿Hay vacantes o inscripciones?

No. Esta es una web de exhibición: no se reciben solicitudes, no se reservan cupos y no se cobran cursos.

¿Qué hace el formulario?

Prepara un borrador de consulta dentro de tu navegador. Podés copiarlo, pero no se transmite ni almacena en ningún servidor.
