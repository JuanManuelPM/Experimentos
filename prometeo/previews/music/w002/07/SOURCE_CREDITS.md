# CUERPO Y CIRCUITO · Procedencia acústica

Fuente: [Meta Open Sound, Meta Nylon Guitar](https://github.com/facebookincubator/Meta-open-sound/tree/main/systems/instruments/meta-nylon-guitar).
Licencia publicada para la colección: **CC0 1.0**. Los OGG son capturas acústicas de notas individuales reales, no una grabación de una improvisación continua.
Se copiaron los archivos binarios a `samples/` conservando su SHA Git original, que figura en `SONGPROJECT.json`.
Referencias artísticas estudiadas, **sin copiar ni samplear sus obras**: [Holden/Zimpel](https://www.ableton.com/en/blog/james-holden-waclaw-zimpel/), [Tignor 2026](https://www.ableton.com/en/blog/input-output-christopher-tignor/), [Tignor 2016](https://www.ableton.com/en/blog/christopher-tignor-risk-and-reward/).
La composición y el procesador son nuevos. Limitación importante: guitarra secuenciada a partir de samples humanos, no una toma acústica interpretada específicamente para esta pieza.
