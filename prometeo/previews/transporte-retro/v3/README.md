# Transporte Retro V3 · Ola 002

Se produjo una **primera escena completa candidata** mediante continuidad V1 + contratos V2, sin reescribir el brief humano. Arquitectura de 12 filas de asientos, conductor, nueve perfiles de pasajeros diferentes, protagonista real CesiumMan GLB animado, ciudad nocturna 3D con ventanas instanciadas, exterior del colectivo, nueve planos, cámara libre, controles táctiles, audio ambiente opcional y timeline.

**Limitaciones reconocidas:** pasajeros secundarios todavía estilizados y poco convincentes de cerca, transición a sentado mediante sustitución, no hay QA GPU/Android ni aprobación artística. El objetivo del flujo@2.0.0 es entregar escena íntegra y mostrar defectos, no cancelar el resultado por estética.

**Fuente:** `source/index.html`, `source/scene.mjs`, `source/capabilities`. Brief y trazabilidad en este directorio. No sustituye ni altera V2.
