# Entre líneas · Personajes 05 · V1
Estudio 3D / Ola 004 / Dúo de conversación.
Proyecto de personajes (no videojuego). Dos humanos **distintos**: Inés (64, silueta alta, rostro anguloso, cabello plateado, anteojos y sastrería granate); Teo (27, silueta más ancha, piel más oscura, pelo rizado, chaqueta verde, ropa informal).
**Técnica elegida:** rig recortable SVG 2.5D dibujado originalmente y escena con profundidad sugerida, sin descargables de terceros, sin dependencias runtime, apto para dispositivos móviles. No es un modelo volumétrico ni GLB: no presentarlo como tal.
**Actuación:** 6 beats de diálogo, mirada interpersonal, turnos de habla con boca móvil, cejas, inclinación de cabeza y dos brazos independientes por personaje. Controles Conversar, Miradas, Reacciones, Gestos y Reiniciar. El silencio/diálogo se muestra mediante texto, sin TTS.
**Arte editable:** todo el vector SVG se conserva dentro de `index.html`; transformar cada grupo `ines-actor` o `teo-actor` en asset independiente si se reutiliza. El código JS permite retarget de poses desde `pose()`.
**Fuentes/rights:** dibujos, textos de diálogo y código originales para esta obra. Sin imágenes/modelos de terceros. Derechos sobre contenido generado sujetos a condiciones aplicables del servicio y a revisión humana.
**Prevención:** antes de producir, se comparó importar activos humanos licenciados (rig reutilizable pero baja certidumbre de diferencia facial y de ropa para dos generaciones) frente a ilustración vectorial original articulada (diseños claramente separados, edición reproducible y coste 0); se eligió esta última para lograr recursos visibles y funcionales en la plataforma disponible.
**QA:** prevención de rutas y anatomía por diseño; revisión técnica pendiente en navegador real/Android y aprobación artística humana pendiente. No se simulan capturas ni tests visuales.
