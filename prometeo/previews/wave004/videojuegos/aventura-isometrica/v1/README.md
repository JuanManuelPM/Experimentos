# La última luciérnaga · W4 / Videojuegos 7

Aventura isométrica 3D jugable: personaje ilustrado (zorro), guardián NPC (búho), isla tridimensional, chispa coleccionable, conversación con elección y **dos finales reales**. 180 s para completar o reiniciar. Controles teclado WASD/flechas, clic/tap sobre el suelo, joystick táctil y botón de interacción.

**Brief literal:** Quiero una pequeña aventura 3D isométrica jugable con personaje, entorno con profundidad, NPC, objeto coleccionable, diálogo/decisión y un objetivo final.

**Flujo fijado:** 2.3.0 / `53bc9e2e4b37c99e92d3494af8dfa4461cd4644b15f980e32497a8428b067b3f`.

**Cómo abrir:** GitHub Pages sirve `index.html`; requiere conexión para importar Three.js v0.180.0, WebGL2 compatible. Los personajes están ilustrados en el código usando CanvasTexture, sin assets externos. No hay humanos compuestos con primitivas. Sin dependencia del resto de la tanda.

**QA:** método de prevención antes de producir; no se declara aprobación artística ni prueba en Android. El usuario revisa la obra y cualquier corrección general del método corresponde a un trabajo separado de CALIBRAR.
