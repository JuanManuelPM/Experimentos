# VECTOR RANGE · Arcade 3D

Prototipo vertical slice 3D con blancos mecánicos móviles a distintas profundidades, raycasting de disparos, chispas, sonido sintetizado, tres rondas (5, 8 y 11 impactos), puntuación, temporizador, victoria/fracaso y reinicio. En PC: mover mouse y clic/espacio para disparar, tecla R para reiniciar. En celular: arrastrar mira, toque simple para disparar o botón FUEGO grande.

Alternativas preventivas antes de producción: sprites/Canvas 2.5D vs. geometría tridimensional extruida WebGL. Elegida la segunda por volumen real y precisión de raycasting. Modelos, arte, escena, CSS y lógica son originales. Three.js 0.180.0 se descarga desde jsDelivr y tiene licencia MIT. Requiere conectividad al iniciar.
