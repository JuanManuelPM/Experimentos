# PROMETEO · Cruce urbano V2 · preview candidata

Abrir: https://juanmanuelpm.github.io/Experimentos/prometeo/previews/cruce-urbano/v2/

Escena 3D interactiva experimental: barrio urbano con cruces semaforizados, peatones animados, 8 vehículos, 12 edificios, entorno 3D y cámara libre.

**Estado:** fuente publicada, página HTTPS verificada, render WebGL2 y calidad artística todavía no comprobados. El extractor web que pudo abrir la página no dispone de WebGL2.
