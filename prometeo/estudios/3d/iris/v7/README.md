# IRIS V7 · Planar sculpt
V6 y V5 quedan intactas. Este módulo importa StyledFace de V6. No añade piezas anatómicas, no corta caras, no decima, no introduce flatShading global. Usa la superficie frontal de triángulos reales y el centro ocular para localizar la punta nasal; puente y punta se aproximan por secciones lineales y un centro plano, con transiciones laterales. Pómulos, mandíbula y mentón se aproximan por planos de secantes con máscaras locales. Se protege el borde inferior nasal, ojos y boca. Los deltas se convierten a espacio local de cada vértice considerando skinning; se conservan morphs y normales originales con corrección local. Desplazamientos limitados; comprobación de inversión/área de triángulos con retroceso, fallback a original si no pasa. No equivale a certificación de colisiones ni de calidad artística.
API: import {PlanarFace, recipe, PRESETS7} from './planar-system.mjs'; const sys=new PlanarFace(scene); sys.identity=recipe(PRESETS7.iris); await sys.load(); sys.setSculpt({amount:1,nose:1,cheeks:.72,jaw:.55}); sys.setSculpt({amount:0}); sys.planarStats.
El cero restaura arrays originales sin acumular deltas. Los controles y recetas V6 se mantienen. Se recalcula al terminar edición anatómica; la animación usa los morphs existentes. Quitar escultura para comparar manteniendo misma identidad, material y cámara. No se reducen triángulos. La nariz, los pómulos y la mandíbula son el alcance; cabello y labios no se reconstruyen en V7.
