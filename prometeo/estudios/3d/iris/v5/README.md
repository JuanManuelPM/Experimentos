# IRIS V5 — anatomía de autor, no recortes
Propietario: studio-3d. V4 se conserva intacta como referencia negativa. El visor V5 importa GLB de CharacterCreator derivados de MakeHuman/MPFB, licencia de datos CC0-1.0 según LICENSE-NOTES.md, commit fijo 852e48f316b90a0937234886630e4fb4cdfd1f78. No se incorpora su código GPL; el adaptador es propio. Los binarios se cargan desde CDN (fallback raw GitHub), no están vendorizados aún.

## Soter: contrato de reutilización
Importar FaceSystem, PRESETS, recipe, FIELDS, HAIR desde face-system.mjs; new FaceSystem(scene); await load(); await setRecipe({name,gender,face:{nose_width,...},hair,skin,hairColor,browColor,irisColor,restBlink,temperament}); setExpression({blink,lookX,lookY,browL,browR}). Valores de identidad en [-.75,.75], expresión de ceja y cierre [0,1], mirada [-1,1]. El objeto recipe es serializable. Presets IRIS/SOTER/NARA demuestran variación, no certifican calidad artística. Morphs auténticos del GLB se aplican a todas sus capas. Cejas: targets adicionales calculados desde bounding boxes de cejas de autor, amplitude 3.8 mm; se deshabilitan si no se encuentran piel y cejas compatibles. Las formas de nariz, labios, orejas y párpados provienen de malla real. No se recortan triángulos de rostro. Se preservan originales y se usan clips de cámara únicamente para retrato. No hay rig oral dinámico, piercing ni cabello rapado personalizado: son pendientes explícitos; no simularlos.
