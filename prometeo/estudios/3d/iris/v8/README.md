# IRIS V8 · Superficies poligonales conectadas
V8 importa V7/V6; sus archivos no se modifican. Sustituye la estrategia de pequeñas correcciones como único recurso por agrupación de triángulos adyacentes de la cabeza según orientación y extensión. Una proyección limitada hacia los planos de cada grupo modifica posiciones compartidas, con protección aproximada de zonas móviles y retroceso por área/orientación; una malla de presentación separa las normales entre grupos y conserva índice, UV, pesos, skin y morph targets remapeados. No es flatShading de cada triángulo. El proxy usa el esqueleto y las influencias del original. Se preservan cejas, ojos, boca y pelo de V6; el cabello no se ha reconstruido. No es decimación: puede aumentar vértices de render. Para recuperar V6 pulsar Suave, o abrir ../v6/. Controles facet.amount, size, shape independientes de identidad; API FacetedFace.setFacet. Pruebas necesarias: frente/perfil/arcilla, comparación 0 vs 100, blink, morphs y ausencia de costuras. Las pruebas geométricas internas no sustituyen inspección visual ni comprueban colisiones.
