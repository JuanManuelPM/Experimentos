# IRIS V9 · Authored planes
V9 importa V6 directamente y descarta el clustering V8. 14 reglas de atlas, varias bilaterales, representan 22 regiones nominales. Fronteras rectas suavizadas calculadas en coordenadas anatómicas relativas a ojos, no al índice de triángulos. Normales de autor en shader y proyección limitada de posiciones sobre planos ajustados a la anatomía, con máscara de protección ocular/oral/nasal y guard de triángulos. No es una retopología ni reducción de triángulos. El cuello se estrecha de forma gradual; el visor recorta hombros y parte inferior. Rapado gráfico opcional: color continuo sobre el cuero cabelludo, sin pelo independiente para cortes cortos; no es un nuevo volumen de pelo. Identidad y morphs se conservan, V6–V8 intactas. API AuthoredFace.setDesign({amount,shape,neck,scalp}); exportación de receta incluye design. Cero restaura posiciones originales y elimina shader de autor; encuadre del busto sigue siendo V9. Validar visualmente frente, perfil, arcilla, parpadeo y cejas. Guard no certifica colisiones ni aceptación artística.
