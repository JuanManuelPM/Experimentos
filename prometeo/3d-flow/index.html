SISTEMA EVOLUTIVO

El flujo actual. Y los anteriores.

Cada versión publicada queda congelada. Las mejoras se documentan con los errores detectados, las diferencias de nodos y pruebas comparables.

Regla de versiones

Una corrección nueva crea un archivo versions/X.Y.Z/flow.json; no reescribe versiones antiguas. Los proyectos vinculan siempre versión y huella SHA-256 del flujo. El campo actual indica qué edición debe usar una producción nueva.
