# PROMETEO · Laboratorio universal de actuación 3D · Candidato

Acting lab experimental de 20 segundos / 480 frames. No es un juego ni un cortometraje artístico aprobado. Reutiliza la base civil congelada v0.1.3 en azul/granate, la lonchera CC0 real en oxblood/sage, el director semántico MIT del Estudio 3D y ruta matemática compatible con rigs por familia.

La aplicación ofrece stage de ensayo, itinerario acercarse-pausa-giro 90°-caminar-interacción, vistas dirigidas/frontal/lateral/libre, play/pause/seek/frame, capturas, exportación JSON, inspector de huesos/clips/orientación y un intento CCD de mano sobre socket. No hay segundo esqueleto verificado; las dos skins **no son dos personajes**.

**Estatus:** tests lógicos Node realizados, WebGL no disponible en el Chromium local. No afirmar caminata con pies apoyados, agarre genuino visual o aprobación humana hasta ver PNG/QA del render. Ver RESULT.json, RECIPE.md, SCENE_LOCK.json, METHOD_DELTA.md y NEXT_ACTION.json.
