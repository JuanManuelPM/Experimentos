# Constructor guard — surface contract

Import guardedGenerate from surface-guard.mjs at the existing procedural generator boundary. It returns {model,report} only on success; the model is unchanged and ready for the existing Three.js viewer. On failure it throws SURFACE_CONTRACT_REJECTED with report. No legacy chair is rewritten.

Contract: surfaces [{id,host,triangles,residual,outward OR oppositeVertexOffset}], exempt {part: reason}, connections [{host,guest,mode,anchor,zone:{center,radius},surface (for intentional pass)}]. Metres, triangle indices zero-based. Specify protected faces from actual mesh topology; opposite offset is for paired shell surfaces and determines local outward orientation. Exempt only parts with no protected patch; every part is classified. A pass is localized to its named surface and convex spherical zone. CONTACTO needs boundary anchor and no detected overlap; ENCASTRE_OCULTO and PASANTE_INTENCIONAL need an interior anchor and local permitted surface intersections. All guests are checked against every protected patch, even without a connection declaration. Residual is checked on an inward-offset patch; not a general solid thickness solver.

Run: node --input-type=module -e "import('./test.mjs').then(m=>{const r=m.run();console.log(JSON.stringify(r,null,2));if(r.some(x=>!x.pass))process.exitCode=1})" from this directory. Existing ARC/HÉLICE structural checks are baselines, not visual approval. RIEL/PÉTALO use the exact existing generator without modifying it, and must be rejected by the producer wrapper. The fixture contract protects only the reported host, not all historical surfaces.

Limits: triangulated closed meshes with consistent local geometry; coplanar contacts are deliberately excluded from crossing detection. Degenerate, open, or undeclared input fails closed. This is a geometric gate, not a raster/material/occlusion test or exact CSG volume proof. Offset triangles can leave seam gaps on curved surfaces; arbitrary near-tangent, edge-aligned or pathological self-intersecting meshes are not certified. Surface completeness depends on declaration. Future producers must use guardedGenerate rather than bypass it. No automatic migration or production promotion.
