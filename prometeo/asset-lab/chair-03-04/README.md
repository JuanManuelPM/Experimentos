# RIEL 03 / PÉTALO 04

Two new original Three.js chair candidates, not recolors. Open index.html?model=rail or index.html?model=petal. The HÉLICE 02 button loads the unchanged original geometry module. All three share an orthographic camera and neutral option. The PNG control captures the actual browser canvas when used.

RIEL uses two curved continuous side runners and a separate open back band; PÉTALO uses a continuous curved shell and a pedestal with radial feet. Shared recipe in RECIPE.json; exact geometry checks in BUILD_RECEIPT.json, reproducible with node test.mjs. Source uses no mesh downloads and does not require Blender. WebGL and Android NOT_RUN in this execution; artistic merit not established. No changes to ROOT or prior works.
