# Pisos modulares / 03
Candidate only. Reuses constructor and gate pinned at 6ebdfe30fde33e3a570f683ac3bb93cfecfb38a3; no alternate engine.
`buildParquet`, `buildWorkshop`, `buildPaving` return named closed meshes, material keys, UVs, metric datum, nominal grid, anchors and assembly relations. Use `buildFloor(kind,{ix,iz,nx,nz,clip:false})` for tiled regions, global coordinates, add all returned parts to the scene (do not translate a second time). Staggered rows intentionally own an east overhang of half a tile; adjacent modules fill the west. For bounded rooms use one region with clip:true to trim the external boundary only. Do not independently clip every interior module. Optional threshold is only for outer north edge. Viewer 1×1/2×2, orbit, overhead, grazing, edge, detail, material/clay, GLB/JSON. GPU and physical Android not tested. Procedural surface maps in viewer.mjs; no external asset dependencies other than pinned constructor/Three.js.
