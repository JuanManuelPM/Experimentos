## Run
From this folder use `python -m http.server 8080`, open http://localhost:8080/ in a WebGL2 browser with access to jsDelivr and raw.githubusercontent.com. WASD/arrows or touch pad; drag to look; reset. No bundler. The existing Three.js 0.181.0 version and CDN convention from Orbital/Forja are reused, not copied. ## Contract and station integration
scene.json is a complete scene/v1 example. Meters, Y up, right handed; Euler XYZ radians; spawn position is feet, camera +1.62m. Each sector position uses floor(x/sectorSize), floor(z/sectorSize); AABBs are global, exact duplicates by ID are allowed; overlaps are spatially indexed. Ground is an explicit collider, not an implicit invisible plane. Missing sectors are bounds. Flat ground, no jump/stair stepping or capsule-vs-triangle physics. Use conservative AABBs or separated wall/floor boxes to keep passages accessible; arbitrary collider overlap and spawn-in-solid are not validated. Unknown namespaced fields are ignored. URL allowlist: immutable raw URLs from this owner repo only; glTF external references must stay within the pinned source commit; no generic arbitrary file uploads. Source license must be checked independently. Dependency parsing cancellation is cooperative and stale results discarded; GLTFLoader subrequests already started are not reliably aborted. No compressed decoder setup or guarantee of all glTF extensions.

The pure runtime is runtime.mjs. mountWorld(manifest,ui) in viewer.mjs owns rendering/controls and returns stop/reset and diagnostics. Integrate Station only after reading its manifest and confirming scale, floors, transforms, collider ownership, and source dependencies. The station author can import runtime.mjs from the same checked-out tree and adapt UI; do not claim interoperability until a real browser traversal. Sector cap 12 (3x3 immediate neighborhood + 3 retention/prefetch); pending sectors cap 2; model cache cap 12 templates, idle 1.5s. These are counts, not hard byte/GPU memory guarantees. Static repeated geometry uses InstancedMesh; skeleton clones and animation mixers use independent state with shared geometry/materials. Disposal performed on release/eviction; actual GPU allocation/release is not verified here.

## Before/after and prevention
Prior Orbital prototype eagerly loaded all assets and only removed groups; new approach leases model templates per sector, cancels pending builds, and bounds resident sectors/cache. Alternative: one huge static scene vs sector streaming; first article selected streaming, independent logic vs coupled renderer. Real GLB header inspection revealed 100x node scale and -90deg X conversion; floor 2m across, use 12m tilesets and conservative props based on transformed bounds. Avoided glTF texture-directory mismatch of prior Orbital by choosing self-contained GLBs. 25 sectors/1000 instances declared; route simulation visits all 25, no floor drop, closes with zero live sectors/models. No physical performance or aesthetics certification.
