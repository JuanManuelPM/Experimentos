# Third-party assets

## Bibata Cursor
Cursor geometry is derived from Bibata Cursor by Abdulkaiz Khatri / contributors. Upstream license: GNU GPL v3 or later. Public/source Lab cursor bytes are embedded in `pointer-assets.js` for portability. The GPLv3 text is included in `LICENSE-BIBATA-GPL-3.txt`.

Upstream: https://github.com/ful1e5/Bibata_Cursor

## Gesture assets
`gesture-assets.js` contains local transformations of the gesture reference image supplied by the user in this conversation. The black montage background was removed, safe transparent margins were added, and a dark outline was added for contrast.
